# Göbekli Tepe Arena v0.1

Tarayıcıda test etmek için hazırlanmış küçük, oval ve hızlı çatışma haritası prototipi.

## GitHub Pages
1. Bu klasörün içindeki dosyaları GitHub reposunun köküne yükleyin.
2. Settings > Pages bölümüne girin.
3. Deploy from a branch seçin.
4. Branch: main, Folder: / (root) seçin.
5. Kaydedin.

## Kontroller
- WASD: hareket
- Mouse: bakış
- Shift: hızlı hareket
- ESC: fareyi bırak

Not: Three.js CDN üzerinden yüklenir; haritanın çalışması için internet bağlantısı gerekir.
